## 📂 Repository Structure

The repository is divided into two primary modules:

### Module 1: Natural Language Processing (NLP)
* `nlp-day01/` - Introduction to Text Processing, NLTK, and spaCy.
* `nlp-day02/` - Feature Extraction (BoW, TF-IDF) and Sentiment Analysis.
* `nlp-day03/` - Word Embeddings (Word2Vec, GloVe) and Sequence Models.
* `nlp-day04/` - Transformers and Hugging Face ecosystem.
* `nlp-day05/` - Project: End-to-end Text Classification & Named Entity Recognition (NER).

### Module 2: Computer Vision (CV)
* `cv-day01/` - Image Processing fundamentals using OpenCV.
* `cv-day02/` - Deep Learning for CV: Convolutional Neural Networks (CNNs).
* `cv-day03/` - Object Detection architectures (YOLO, SSD).
* `cv-day04/` - Image Segmentation and Face Recognition.
* `cv-day05/` - Project: Real-time Object Detection Pipeline.

*Note: Datasets too large for GitHub will be shared via drive links inside the respective daily folders.*
